# Encrypted File Vault (CLI Tool)

## Project Overview
A secure command-line tool that encrypts and decrypts files using a password. It guarantees both data confidentiality and cryptographic integrity. This project is developed for the CADT Cryptography Final Course Project.

## Core Cryptographic Architecture
- **Symmetric Cipher:** AES-256 in Galois/Counter Mode (AES-GCM) for Authenticated Encryption.
- **Key Derivation Function (KDF):** PBKDF2HMAC or Argon2id to derive a secure 256-bit key from a user password.
- **Integrity Verification:** 16-byte Authentication Tag generated by AES-GCM to detect file tampering.
- **Entropy:** Secure random generation (`os.urandom`) for Salt (16 bytes) and Nonce (12 bytes).
